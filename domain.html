আপনার কাস্টম ডোমেইন সেটআপ করুন

আপনার নিজের কেনা ডোমেইন এখানে সেটআপ করতে পারবেন। আপনার যদি নিজের কেনা ডোমেইন থাকে, যেমন example.com, তাহলে সেটি এখানে লিখে আপনার GHOTI BUILDER স্টোরের সাথে কানেক্ট করতে পারবেন।

আপনার কাস্টম ডোমেইন

আপনার নিজের কেনা ডোমেইন সেটআপ করতে পারবেন।

আপনার বর্তমান ডোমেইন:
example.com
সঠিক ডোমেইন লিখুন।
গুরুত্বপূর্ণ
ডোমেইন সেভ করলেই আপনার DNS স্বয়ংক্রিয়ভাবে পরিবর্তন হবে না। আপনাকে আপনার Domain Provider-এর DNS Settings থেকে CNAME Record নিজে যুক্ত করতে হবে।

আপনার ডোমেইনে CNAME যুক্ত করুন

আপনার ডোমেইন যেখান থেকে কিনেছেন, সেই Domain Provider-এর DNS Management / DNS Settings-এ গিয়ে নিচের CNAME Record যুক্ত করুন।

Type Name / Host Target / Points to TTL Action
CNAME www store.ghotimarket.com Auto

DNS কোথায় পরিবর্তন করবেন?

আপনি যেখান থেকে ডোমেইন কিনেছেন, সেই ওয়েবসাইটে লগইন করুন। তারপর Domain Management → DNS Management / DNS Settings এ যান।

  • ১আপনার Domain Provider-এ Login করুন।
  • ২আপনার Domain নির্বাচন করুন।
  • ৩DNS Management / DNS Settings খুলুন।
  • ৪Add Record / Add DNS Record এ ক্লিক করুন।
  • ৫Type = CNAME নির্বাচন করুন।
  • ৬Name/Host = www লিখুন।
  • ৭Target/Points To = store.ghotimarket.com লিখুন।
  • ৮Save Record করুন।

আপনার ডোমেইন যেখান থেকেই কেনা হোক, DNS Settings থেকেই CNAME যুক্ত করতে হবে:

Namecheap GoDaddy Cloudflare Hostinger Porkbun Other Providers

ডোমেইন ফরম্যাট ও আপডেট নোটিশ

১. শুধু ডোমেইন লিখুন। যেমন: example.com অথবা www.example.com (কোনো https:// বা trailing slash লিখবেন না)।

২. CNAME পরিবর্তনের পর ইন্টারনেট জুড়ে DNS আপডেট হতে কিছু সময় (কয়েক মিনিট থেকে ২৪ ঘণ্টা পর্যন্ত) লাগতে পারে।

৩. আপনি যদি www.example.com ব্যবহার করতে চান, তাহলে CNAME-এর Host/Name হবে www। আপনার root domain example.com থেকে www.example.com ব্যবহার করার জন্য DNS provider অনুযায়ী অতিরিক্ত configuration (যেমন: Domain Forwarding) প্রয়োজন হতে পারে।
